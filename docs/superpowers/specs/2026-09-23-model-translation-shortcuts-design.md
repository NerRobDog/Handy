# Шорткаты перевода и смены модели — дизайн

Дата: 2026-09-23. Ветка: `feat/model-shortcuts` в форке `NerRobDog/Handy` (база — `cjpais/Handy@8f9cf53`). Beads: эпик `handy-d5m`.

## Контекст и цель

Пользователь держит три модели: Parakeet V3 (быстрая диктовка), Whisper Large v3 (перевод на английский) и Whisper Large v3 Turbo. Turbo нужна только как «Whisper без перевода»: в Handy перевод — одна глобальная галочка `translate_to_english`, а применяют её только модели с `supports_translation = true` (`src-tauri/src/managers/transcription.rs:1854`). У Turbo и Parakeet этот флаг `false` (`src-tauri/src/managers/model.rs:646`), поэтому сейчас выбор модели в трее фактически и есть переключатель перевода.

Цель — два глобальных шортката. Первый включает и выключает режим перевода, сам подставляя переводящую модель и возвращая прежнюю. Второй переключает модели по кругу среди отмеченных звёздочкой, как раскладки клавиатуры. Работа только для форка, но в стиле проекта: тесты, i18n, без хаков.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Что делает смена модели | Круг по избранным (★), порядок — в котором ставились звёздочки |
| Избранных меньше двух скачанных | Круг по всем скачанным моделям, по алфавиту (как в трее) |
| Что делает шорткат перевода | Вкл: переключиться на последнюю модель, на которой шёл перевод, и включить галочку. Выкл: снять галочку и вернуть модель, активную до включения |
| Обратная связь | Короткая плашка в оверлее + пункт-галочка «Переводить на английский» в трее |
| Клавиши по умолчанию | macOS: ⌃⌥T (перевод), ⌃⌥M (модель). Windows/Linux: Ctrl+Alt+Shift+T/M (Ctrl+Alt+T в Ubuntu открывает терминал) |
| Во время записи/распознавания | Оба шортката игнорируются (как трей прячет выбор модели) |
| Галочка перевода в окне настроек | Остаётся простым флагом без смены модели |
| Языки интерфейса | Новые строки переводятся на все 27 локалей, чтобы `check:translations` в CI был зелёным и трей нигде не был пустым |
| Сборка .app | Свой workflow в GitHub Actions: macOS arm64, без подписи, без автообновления |

## Поведение

### Новые настройки (`AppSettings`)

- `favorite_models: Vec<String>` — id избранных моделей в порядке добавления. Новая звёздочка встаёт в конец, снятая удаляется. По умолчанию пусто.
- `translation_model: Option<String>` — последняя модель, на которой был включён перевод. По умолчанию `None`.
- `translation_return_model: Option<String>` — модель, к которой вернуться при выключении перевода. По умолчанию `None`.

Все три поля имеют `serde(default)`: существующий `settings_store.json` загружается без ошибок и без срабатывания салважа. Новые привязки `toggle_translation` и `cycle_model` добавляются в `get_default_settings().bindings`. Существующие хранилища получают их автоматически: при загрузке недостающие привязки дописываются из стандартного набора (`src-tauri/src/settings.rs:1035`). Регистрация идёт по стандартному набору (`tauri_impl::init_shortcuts`, `handy_keys`, `register_all_shortcuts_for_implementation`), отдельный код регистрации не нужен.

### Шорткат перевода (`toggle_translation`)

Срабатывает на нажатие, отпускание игнорируется. Если идёт запись или распознавание, ничего не делает.

Включение (галочка сейчас снята):

1. `translation_return_model := selected_model`.
2. Выбор модели-цели (чистая функция), по порядку:
   1. `translation_model`, если она скачана и умеет переводить;
   2. текущая модель, если умеет переводить;
   3. первая скачанная переводящая модель из `favorite_models`;
   4. первая скачанная переводящая модель по алфавиту.
3. Если цели нет — ничего не менять, плашка «Нет скачанной модели с переводом».
4. Если цель отличается от текущей — `switch_active_model(цель)` в фоновом потоке, по образцу обработчика трея (`src-tauri/src/lib.rs:325`). При ошибке загрузки галочка не меняется, `translation_return_model` откатывается, плашка сообщает об ошибке.
5. `translate_to_english := true`, `translation_model := цель`, событие `settings-changed`, обновление трея, плашка «Перевод: вкл · <модель>».

Выключение (галочка сейчас стоит):

1. `translate_to_english := false`.
2. Если `translation_return_model` скачана и отличается от текущей — переключиться на неё. Иначе остаться на текущей.
3. `translation_return_model := None`, событие `settings-changed`, обновление трея, плашка «Перевод: выкл · <модель>».

### Шорткат смены модели (`cycle_model`)

Срабатывает на нажатие, во время записи и распознавания игнорируется.

1. Список круга (чистая функция): скачанные модели из `favorite_models` в их порядке. Если таких меньше двух — все скачанные, отсортированные по имени, как в трее (`src-tauri/src/tray.rs:325`).
2. Следующая после текущей, с переходом с конца на начало. Если текущей нет в списке — первая. Если в списке одна модель и она уже текущая — ничего не делать.
3. `switch_active_model` в фоновом потоке, затем обновление трея.
4. Плашка «<модель>». Если перевод включён, а модель переводить не умеет, добавляется «— не переводит».

### Учёт `translation_model`

После любого успешного `switch_active_model` (шорткат, трей, окно настроек): если `translate_to_english` включён и новая модель умеет переводить, `translation_model := новая модель`. Логика живёт в одном месте, внутри `switch_active_model`, поэтому покрывает все пути.

### Блокировка во время работы

Нужен публичный предикат «Handy занят»: идёт запись или распознавание. Сейчас это состояние видно только трею (`TrayIconState::is_busy`, `src-tauri/src/tray.rs:49`, поле приватное). Предикат выносится так, чтобы им пользовались и трей, и новые действия. Смену модели посреди распознавания это исключает, а параллельные загрузки дополнительно отсекает `try_start_loading`.

## Интерфейс

- **Страница «Модели».** На карточке скачанной модели появляется кнопка ☆/★ рядом с корзиной. У отмеченных виден номер в круге (★1, ★2). Клик вызывает новую команду `toggle_favorite_model(model_id)`: она добавляет или удаляет id и шлёт `settings-changed`. В онбординге звёздочки нет: `ModelCard` рисует её, только если передан обработчик.
- **Настройки → Общие.** Под «Диктовкой» и «Отменой» две строки `ShortcutInput`: `toggle_translation` и `cycle_model`. Тексты берутся из `settings.general.shortcut.bindings.<id>.name/description`.
- **Трей.** В обычном меню рядом с выбором модели — `CheckMenuItem` «Переводить на английский», его состояние равно `translate_to_english`. Клик выполняет то же действие, что шорткат. В меню занятого состояния пункта нет. Изменение галочки входит в `MenuInputs`, чтобы меню перестраивалось.
- **Оверлей.** Новое состояние `notice` с иконкой (языки для перевода, звуковая волна для модели) и одной строкой текста, длинное обрезается многоточием. Показ около 1,5 с, затем скрытие через существующий механизм с `OVERLAY_SHOW_GENERATION`. Если в это время началась запись, она вытесняет плашку, а устаревшее скрытие отбрасывается. При отключённом оверлее (`OVERLAY_ENABLED = false`) плашка не показывается.

## Сборка форка

- **`.github/workflows/fork-build.yml`:** запуск вручную (`workflow_dispatch`), один раннер `macos-26`, цель `aarch64-apple-darwin`. Переиспользует `build.yml` с `sign-binaries: false`, `upload-artifacts: true` и переопределением `bundle.createUpdaterArtifacts = false`, чтобы сборке не требовался `TAURI_SIGNING_PRIVATE_KEY`.
- **Выключатель автообновления на этапе сборки.** Сейчас `update_checks_forced_disabled()` читает `HANDY_DISABLE_UPDATER` только из окружения во время работы (`src-tauri/src/settings.rs:1195`). Добавляется проверка `option_env!("HANDY_DISABLE_UPDATER")` на этапе компиляции, workflow её выставляет. Сборка форка никогда не скачает upstream-релиз поверх себя. Интерфейс покажет обновления отключёнными, как в Nix-пакете.
- Upstream-workflow `Main Branch Build` в форке отключён (`gh workflow disable`): без сертификатов Apple он падал на каждом синке.

## Тестирование

Rust, модульные тесты рядом с кодом:

- настройки: старое хранилище без новых полей загружается, поля получают значения по умолчанию; новые привязки дописываются;
- выбор цели перевода: все четыре ступени, цель не скачана, цель не переводит, переводящих моделей нет;
- модель возврата: не задана, удалена, совпадает с текущей;
- круг моделей: пусто, одна модель, текущая вне списка, переход с конца на начало, меньше двух избранных, порядок звёздочек, нескачанные избранные пропускаются;
- `toggle_favorite_model`: добавление в конец, удаление, повторное добавление;
- выключатель обновлений на этапе компиляции.

Фронтенд: в проекте нет модульных тестов компонентов, поэтому `tsc`, `bun run lint`, `format:check`, `check:translations` и ручная проверка.

Ручная проверка в `bun run tauri dev`. Перед запуском выйти из установленного Handy 0.9.6: у dev-сборки тот же идентификатор `com.pais.handy`, общий файл настроек и защита от второго экземпляра. Сделать копию `~/Library/Application Support/com.pais.handy/settings_store.json`. Сценарии:

- ⌃⌥T с Parakeet: переход на large-v3 и обратно;
- ⌃⌥M по кругу из двух и трёх звёздочек;
- шорткаты во время записи игнорируются;
- плашка поверх записи не появляется;
- галочка в трее и в настройках синхронна.

## Вне рамок

- Отдельный шорткат «диктовать сразу с переводом» (выбор модели на каждую запись).
- Звёздочки в трее или в выпадающем списке моделей внизу окна.
- Одновременная загрузка двух моделей в память.
- PR в upstream: Handy под заморозкой фич, новые фичи сначала обсуждаются в Discussions.

## Риски

- Смена модели загружает её в память (large-v3 Q5_K_M — около 1 ГБ), первое нажатие после переключения ждёт загрузку. Это та же цена, что у переключения в трее сегодня.
- Сборка из Actions не подписана. При первом запуске Gatekeeper потребует «Открыть всё равно» или снятие карантина, а macOS заново спросит доступ к «Универсальному доступу» и микрофону.
- Сборка идёт только через нативные инструменты: `~/.local/opt/handy-dev-env.sh` (rustup, CMake 4.4.3 universal). Intel-cmake из Homebrew ломает `transcribe-cpp-sys`: определяет `CMAKE_SYSTEM_PROCESSOR: x86_64`.
